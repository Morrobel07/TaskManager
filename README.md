Un ejecutable de consola sencillo y ligero para gestionar tareas pendientes, en progreso y completadas directamente desde la línea de comandos, desarrollado en **C# (.NET)** sin dependencias de librerías externas.

---

Características

- Gestión completa de tareas
- Almacenamiento local
- Sin dependencias externas
- Filtros de búsqueda
- Trazabilidad

repositorio: https://github.com/Morrobel07/TaskManager
